# 0.5.6：常驻沙箱连接与可中断准备

Windows OpenSSH与本机Docker使用按沙箱隔离的常驻通道；批量读取项目说明和Skills，减少重复认证和RPC。沙箱准备期间可切换会话和打开管理入口；A会话提交后切到B，准备完成仍在A执行，B的草稿和图片保持。取消、停止及销毁不会晚到启动原消息。

请求排队/执行超时不再直接关闭健康通道，迟到回复有界排空；补SSH保活、独立探活、搜索远端取消及UDS租约、有限清理重试和非UTF8路径。数据库工作移出事件循环，补齐销毁服务端确认、操作事实保存、观察错误隔离与watcher收尾。

envd以受保护控制身份运行，任务降为UID1000且零能力；工作区IO有路径及权限校验，控制日志和socket不再由任务身份访问。隔离与审批仍各自检查，不代表恶意代码隔离已通过所有生产场景验证。

## 升级

先正常停止旧服务，保留配置和数据：

```sh
nyt service stop
python -m pip install --upgrade naiyue-test-agent==0.5.6
nyt --version
```

Release提供Windows安装包与Linux amd64离线镜像。Agent为0.5.6，envd按独立版本合同为0.5.5，AITest Kit为0.6.0。旧0.5.3镜像不能提供本轮attach和权限合同；导入新标签后由用户更新验收模板并创建专用新会话，不直接迁移旧卷。镜像包内包含校验、导入和check.sh说明；Windows包不包含Python和完整依赖wheelhouse。

本机ARM64及amd64 QEMU、原生SSH、双沙箱、权限、取消、输出和归档已有记录；公司Windows/两跳VPN/Docker19.03原机由用户发布后验证。本机耗时不是公司性能保证，模型请求延迟与大输出传输另行衡量。journal保持FULL持久性，密码/MFA及主机级SSH复用不在本版。
