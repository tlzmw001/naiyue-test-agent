# Naiyue Test Agent 0.4.0

本版本加入会话历史查询、项目与个人记忆，并把应用输出归档移到执行目录外。支持平台仍为macOS Apple Silicon、Linux x86_64/ARM64和Windows x64。

## 会话历史与记忆

- `history`按需列出、搜索和读取同一工作目录的已保存可见会话，包括已登记子实例；查询不恢复或执行目标会话。
- `memory`支持项目/个人记忆的查询、记录、更正、停用与遗忘。保存前核对真实来源和版本；候选与正式记忆按类型期限、证据和适用条件管理。
- 完整根用户轮正常保存后，按配置阈值或显式`refresh_overview`请求在后台整理概览与记忆。每批调用一次已有配置语言模型，不需要embedding模型，也不另加评分或格式修复模型。
- 新用户轮有界注入偏好和相关记忆短索引，首次提供其他会话的近期索引；需要原文时继续使用`memory`或`history`查询。
- CLI/Web复用工具选择、权限和后台任务管理。后台任务可查看批次、保存/失败计数并停止；用量和运行诊断单独标注“记忆整理”。上下文面板提供索引条数与估算token，尚无逐条实际注入审计页。

已有会话保留原工具选择，可从现有入口启用`history`和`memory`；仅在工具可用、配置启用且保存正常等条件满足时进行自动整理。关闭阈值整理但保留显式维护可配置：

```toml
[memory]
auto_enabled = false
```

默认阈值为新增8个完整正常用户轮或20000个可见用户/助手字符，任一达到即登记。默认后台输出通道仍为`text`；只有确认模型和网关支持时才显式选择`json_schema`或`function_calling`。详见[记忆工具与配置](../memory-tool.md)、[历史查询](../history-tool.md)及[设置示例](../examples/settings.example.toml)。

## 输出归档与模型上限

Shell、后台任务、AITest和MCP的新受管输出归档使用可信应用配置派生的位置：

- 持久项目：`data_dir/workspaces/<项目UUID>/artifacts/naiyue-agent-output/`。
- 无项目身份的临时会话：`data_dir/sessions/<session_id>/artifacts/naiyue-agent-output/`。

归档实际位置必须在执行目录外。已有后台任务冻结其归档范围，执行目录移动后仍可保存、查看与停止。新结果返回绝对归档路径，后续Read继续检查原文件权限；MCP可选归档失败保留已知远端结果，不重复调用。旧项目目录中的归档文件不自动搬迁或删除，旧引用保留原展示语义。

修复OpenAI Responses的单次记忆/压缩输出上限被模型默认值覆盖的问题；共享模型及根Agent正常请求的配置默认上限保持不变。

## 升级与效果边界

```bash
python -m pip install --upgrade naiyue-test-agent==0.4.0
nyt --version
```

项目数据库按现有升级前备份机制迁移到schema17，个人记忆库使用format2及DELETE/FULL。项目备份包含其记忆和概览，不包含个人记忆库或库外完整输出；已有格式的个人库升级使用独立一致性快照。实际用户配置不会自动改写。

自动提取的分类、噪声和候选质量仍需真实任务观察。已有固定样本回归不能证明独立泛化效果；来源引文匹配也不等于自然语言语义已被程序证明。检索使用本地词项与FTS5/BM25，不承诺跨语言或任意同义表达都能命中。

后台任务登记保留在当前进程中，重启不自动重放；已保存概览与记忆持久保留。会话索引反映已保存状态，不提供跨会话文件锁或实时协同保证。本版本未加入worktree创建、项目身份/执行目录重构或执行沙箱。
