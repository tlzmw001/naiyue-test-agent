# 0.5.3：Windows 进程、沙箱快照与结果边界修复

本版修复 Windows 后台子进程闪出控制台窗口，并将 Git 快照逐文件启动进程改为批量写入和读取。准备失败会清理应用拥有的半成品目录；无会话、活动环境、结果或交付引用的输入可定向回收，避免正常删除会话后永久占用快照额度。

发布前复核还修复了跨平台软链接边界：大小写或 Unicode 等价拼写导致链接含义不一致时明确拒绝，并覆盖首次结果校验与历史结果合并入口。快照遵循真实 Git 的 core.filemode/core.symlinks 配置，保留执行位和链接类型。内部环境创建与会话删除使用一致的所有权保护，避免失去会话归属的运行中容器。

## 升级控制端

等待活动任务完成，用 `nyt service stop` 正常关闭旧服务，在原安装环境执行：

```sh
python -m pip install --upgrade naiyue-test-agent==0.5.3
nyt --version
```

保留模型、SSH 配置及数据目录。Agent 与 envd 继续独立版本管理；本次提供 envd 0.5.3 新镜像，包含 AITest Kit 0.6.0 基础 CLI 及依赖。项目特有的业务依赖仍需按项目配置。

## Linux/amd64 离线镜像

从本页附件下载 [离线 ZIP](https://github.com/tlzmw001/naiyue-test-agent/releases/download/v0.5.3/naiyue-envd-0.5.3-aitest-kit-0.6.0-linux-amd64-offline.zip) 和 [SHA-256](https://github.com/tlzmw001/naiyue-test-agent/releases/download/v0.5.3/naiyue-envd-0.5.3-aitest-kit-0.6.0-linux-amd64-offline.zip.sha256)。ZIP 包含镜像 tar、同源兼容检查器、check.sh、manifest、内部校验清单和导入说明。

先核对 ZIP 与内部 SHA，确认仍使用原 Linux Docker daemon，再按包内 README 导入并执行 check.sh。新标签是 `naiyue-envd:0.5.3-aitest-0.6.0-reviewed-amd64`；新会话配置使用该镜像，旧会话保留原绑定，不覆盖旧镜像或删除旧卷。镜像和 wheel 不混入控制端的 PyPI 四平台发行集合。

## 已知边界

仍被结果审查或交付历史引用的快照继续保留并计额。历史已删除会话的孤儿通过内部 `retire_input(project_id, input_id)` 显式恢复，不自动扫描、不提供新增 UI/CLI。

本机真实 Docker 的输入、结果、进程和归档重导入验证通过；Windows 文件模式用真实 Git 配置回归。公司 Windows、两跳 SSH、旧 Docker/kernel 和网络策略仍需原机验收，普通密码后台交互仍未实现。协议兼容不替代平台运行证据。
