# Naiyue Test Agent 0.5.13

正常结束的旧项目会话可以重新打开并续聊。恢复时忽略已退役的 `cloud_result_read`，其余工具和检查点照常校验。原历史继续可读，新版 `cloud_result` 可在工具菜单单独选择。

删除会话时，确认框会显示等待状态。后端拦截删除时，确认框显示实际原因，例如该会话仍关联云端任务。云端请求的连接错误日志增加 `operation`、`phase` 和 `error_type`，便于定位失败阶段。

## 升级本机

让本机工作正常结束，在原 Python 环境中停止服务并安装正式版。

```sh
nyt service stop
python -m pip install -U "naiyue-test-agent==0.5.13"
nyt
```

使用显式 `--settings` 或 `--config` 时，停服和启动沿用原路径。打开终端新打印的链接。曾安装 v0.5.12 Windows 验证包的用户可以直接升级。旧库首次打开仍按原流程备份和迁移。

使用本版会话和删除修复只需更新本机 Agent，现有 0.5.12 Coordinator 和 Runner 可以继续使用。发布附件提供四平台 wheel、同源云端离线 ZIP、校验和与 Updater 索引。选择新版 Runner 模板时，最低 Coordinator 版本为 0.5.12，测试环境仍使用 AITest Kit 0.7.0。
