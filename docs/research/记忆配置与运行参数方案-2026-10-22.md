## 1. 当前项目事实与最小接法

`naiyue_test_agent/settings.py`的AppSettings是冻结的启动配置，当前没有memory节；load_settings分别处理各节非法值，TOML不可解析仍阻止启动。`model_access/__init__.py`已有模型目录、单次输出绑定和模型上下文/输出/请求限制；当前默认请求60秒、SDK重试2次、上下文128000 token、最大输出16384 token。这些是当前源码事实，不是对所有供应商实际窗口/计费的保证。

建议在现有settings.toml增加memory配置节，沿用加载和严格字段校验；不再创建配置文件、供应商或独立模型服务。不复用上下文压缩的触发/写回算法；仅复用模型目录、请求适配、估算/额度及观测。普通记忆辅助失败不改变已经结束的主Agent结果，必要写入失败仍明确反馈。

## 2. 功能、模型与触发（已确认）

| 设置职责 | 初始建议 | 语义 |
| --- | --- | --- |
| 功能总开关 | 开启 | 控制概览/记忆自动准备、整理和memory入口；关闭不删库、不自动注入/写入。原始会话history查询仍独立可用，工具选中/许可继续沿现有活动集合。 |
| 自动整理开关 | 开启 | 关闭后不按阈值登记新自动任务，保留查询、显式记录/更正/遗忘与显式整理；不产生隐式模型请求。 |
| 整理model_id | 省略时继承登记任务时会话当前模型 | 可指定已登记model_id；登记时冻结实际模型及支持的请求参数，不因后续会话切模改变任务，不另配凭证或新模型。 |
| 新增完整根用户轮阈值 | 8轮 | 以成功必要保存后的完整用户轮计数；模型—工具循环、审批续跑不重复算新用户轮。 |
| 新增可见正文阈值 | 20000字符 | 计已保存用户/助手可见正文的Unicode字符数，不计隐藏思考/system、二进制和工具原始洪峰；工具证据仍按有界投影提供。与轮数阈值为OR，成功登记后按既定来源上界推进计数基准。 |

两个开关职责不同：仅关闭自动整理不应导致已有记忆查询和用户显式管理失效；总开关关闭代表功能未启用，不能由主Agent一次工具调用绕过。自动触发仍只发生在已确认保存点，不加空闲定时器。启用带来的后台调用使用现有配置语言模型并产生其实际用量，不承诺无成本。

## 3. 整理任务额度（已确认）

| 设置职责 | 初始建议 | 边界 |
| --- | --- | --- |
| 单批总输入 | 16000估算token | 含约束/来源信封、旧概览、新材料和相关记忆；同时受实际模型配置窗口及输出预留约束，超限先分批/缩小投影。 |
| 单批模型输出 | 最多4096 token | 与所选模型既有输出限制取较小值，单次请求绑定，不修改共享模型实例；不另开格式修复模型。 |
| 每批新增/更新建议 | 最多8条 | 包含相关旧候选更新，允许零条；单条正文最多800字符、别名最多5个，概览正文最多1200字符；独立上限不能作为必须填满的产出配额。 |
| 整次任务总时限 | 300秒 | 从成功登记开始，含排队、分批、模型SDK重试和解析/提交准备，单次请求受剩余时间约束；不把300秒重新给每批。 |
| 每任务最大批数 | 3批 | 总时限/批数任一到达不再开始新批；保留独立成功，未处理/失败范围如实标注，不跨任务自动补漏，用户可显式重整。 |
| 应用内整理并发 | 1个任务 | 跨会话共享；同一会话一个在途任务，重复目标合并，沿用已确认所有权，不占用已结束根run或新造用户轮。 |
| 待处理会话目标上限 | 32个 | 只保留有界的每会话目标，不积累每轮单独任务；满时明确拒绝新登记、记安全诊断，显式入口返回忙。 |

估算token用于规划输入，不等于供应商真实计费用量；实际请求用量仍走已确认purpose=memory。总时限只约束本后台任务，不停止主Agent任务。到时取消未完成模型/停止后续工作；已进入必要提交/资源收尾的操作须确认终局，不能因取消等待就伪称事务未发生或资源已回收。

队列满而未成功登记，不返回accepted、不推进触发基线；之后新的正常用户轮可以再次尝试登记。这与已经接收、处理后失败的来源不同：后者仍按既定规则跳过，不自动补做。已接收目标的排队等待消耗其总时限，不建立无限等待或重启接管队列。

## 5. 配置生效及TTL变更（已确认）

首期沿AppSettings启动读取，修改后重启生效，不为记忆新建热加载机制；已登记任务冻结模型/额度。开关变化不删除历史；已接收后台任务的停止/进程退出仍走既定停止与资源收尾合同，不自动重启接管。

TTL类型/初始时长及变更时点均已确认：新TTL只用于后续新建或有实质补证/确认后更新的条目，提交时保存采用的策略及实际截止时间；已有条目继续原截止时间，不批量改历史。依据时间仍来自真实来源，不能因为配置改变/重新提取续期；明确来源期限始终取早，过期/遗忘内容不能仅靠调长TTL自动复活。

这个已确认选择的代价是缩短TTL不会立即缩短既有条目期限；后续若需统一重算既有条目，应另行决定，不把查询时当前配置和历史已写回状态混用而产生不一致。

memory节字段/取值或所指模型非法时，建议明确记录安全字段级诊断并禁用本模块，不默用可能产生额外模型调用的默认值；普通Agent/原始history仍可工作，memory调用明确返回配置不可用。全局TOML语法/权限等现有启动失败规则不改变。日志不输出凭证、原始敏感正文或完整配置。
