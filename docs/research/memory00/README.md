# Memory-00离线实验

这里只是Spec127-00研究代码，生产模块不导入。本轮使用明确标注的合成数据、两个独立内存SQLite库和标准库，无模型/网络/真实用户库访问。

固定输入fixtures.json包含40条记忆、24条检索查询（12校准/12验证）、12段提取语义材料和4条流程；后两项只校验结构，尚未执行模型/产品工作流。protocol.json记录在检索实现前冻结的输入SHA-256及候选参数。

在仓库根目录使用已存在的新证据目录，结果文件必须尚不存在：

```bash
.venv/bin/python -m pytest docs/research/memory00 -q
.venv/bin/python -m docs.research.memory00.benchmark --stage calibrate --output build/<本次证据目录>/frozen.json
.venv/bin/python -m docs.research.memory00.benchmark --stage evaluate --frozen build/<本次证据目录>/frozen.json --output build/<本次证据目录>/result.json
```

calibrate只用校准标签评分选参；evaluate要求数据/代码/协议哈希仍相同。三路线均使用相同正文/别名、锚点精确匹配、范围/状态/期限/条件过滤、RRF跨库合并和最终权威重验；仅索引/词项和本地排名不同。FTS原始BM25值不跨库比较，适配词只用于索引，返回始终是原文。

Recall@8为有答案查询的相关ID召回比例平均；precision_returned_at_8为非空返回的相关ID比例平均，空结果不填成100%；另外逐条保留hits/limit的precision_at_8、必命中/禁止结果和无答案是否为空。禁止/必命中/无答案作为门禁，不用平均分掩盖失败。

校准只在预定三组权重中选，验证集用于比较并选择路线，故不是最终独立泛化测试。没有大规模、业务或跨平台成绩；采样耗时不作为SLA。原文子串基线是同条件字面搜索，不代表Claude/模型多轮改词的效果。真实语义提取在04显式整理接通后再验。

实际结果见[检索实验结果](检索实验结果.md)及[逐查询结果](results-summary.json)：首期选中文二元字组/技术词项适配FTS/BM25，标题/别名/正文3/2/1、RRF60。留出必命中10/10、禁止0、无答案2/2，但返回精确率81.25%，「测试类」只1/8相关且不在首位。它是候选索引方案，不是语义正确性保证；真实产品尚未接线。运行失败保留完整诊断，不修改固定标签来制造成功。
