# Spec127-00d：00b基线的精确展示去重对照

2026-10-22。用户批准继续单变量实验；本片仅离线研究，不修改产品、实际配置/用户库、依赖或版本，不调用模型/网络，不提交发布。00c源码已按frozen-v1全部哈希保存到build/spec127-00d/baseline/memory00，旧证据和数据不改。

## 1. 目标与当前链路

00c主题筛选出现旧集合回退，不能把主题门槛变化与去重效果混为一谈。本片固定00b字段1/1/1、完整词段优先/无则覆盖1/2回退、RRF60、候选50、结果8。唯一对照为筛选后是否精确折叠展示副本；不采用主题启发式、近似合并或MMR。

正常链：ResearchIndex按可信范围/状态/期限/条件/锚点产生候选并核对权威版本→00b筛选得到至多50个合格项→原顺序精确折叠→取前8条→返回实际代表ID及副本ID。两路线候选ID顺序必须相同，否则实验失败。折叠前不能先截成8条，否则无法检查释放的位置是否容纳新事实；存在完整表达时仍不补弱匹配。

精确键为scope/workspace/kind/machine/target/module及原始title/body；保留大小写、数字、否定、路径、换行与缩进，不归一空白。别名不作为同一事实的文本依据；副本保留独立ID，详情/版本/期限不发生合并或写回。旧00c空白归一实验保持原分支，新的严格原文键只用于本片。

失败链：合格项本就只含一个事实→折叠后少返回，不补不合格项；相关项落在50候选之外→仍漏召回；主题/语义误判→原00b错误如实保留。代码缩进不同不能折叠成同一展示项。未知作用域/到期等仍由原引擎排除，不让去重恢复被过滤项。

## 2. 样本、指标与判断

复用已观察的00（24query）、00b（144query）、00c（144query）共312query；都标为observed，不声称独立泛化。数据/标签/候选方式不变，protocol固定两路线各一个配置。保留原split只便于比对，不用split成绩挑配置。无需新增大量合成集合。

复用既有run_queries/summarize；候选ID只用于证明对照一致，不参与选择。保留真实actual_ids，fact_groups仅在算法返回后做evaluation_ids映射，副本ID不能取得独立事实覆盖奖励。

同时报告记录precision、不同事实有效返回率、事实召回、首条/MRR、冗余、无答案、禁止项、返回数、每query新增/遗漏相关与不相关事实。候选顺序一致为实验有效性硬条件。产品候选门禁：禁止0、旧required保持、无答案不新增错误、每query不丢基线已覆盖的相关事实、且无query增加不同不相关事实。任何门禁失败都不宣称无代价改进；即使通过，也只说明该合成样本的适用性，不自动接产品。

去重不解决完整词段层排除相关弱匹配、主体对照提及、近重复和候选池外召回；明确区分减少副本与找回新事实。固定配置后只运行对照与确定性重跑，不依结果调整键、参数或标签。

## 4. 实际结果与剩余决策

本片已执行，[实际结果](../research/memory00/精确展示去重单变量实验结果.md)保留所有逐query变化与标注争议。312对候选ID/顺序相同；旧00/00b共168query的返回不变。00c已观察144query中，事实召回74.72%→88.06%、事实有效率38.95%→67.18%、冗余232→68，24query新增相关事实、无丢失基线已覆盖相关事实；记录precision89.98%→86.81%。无答案0/52、禁止0，3query新增原标注外事实，candidate_gate_passes=false，不自动升级产品默认。

其中两条标注外结果属于相邻测试知识，存在相关性争议；第三条为接口存档定位而非验证规则。保留原标签，不将改标后的成绩冒充原门禁通过。精确折叠收益与自动补位风险分开讨论，剩余决策为首期是否允许补位；不为通过门禁事后更改本片两路线或参数。

研究116项通过，624条新排名及旧00c快照180条排名重跑一致；输出覆盖/链接/指纹检查通过，原引擎、00b选择器和三份样本不改。产品01—06尚未实施，无用户独立调试/掌握的新证据。
