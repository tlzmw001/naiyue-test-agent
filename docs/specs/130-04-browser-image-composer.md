# 130-04 浏览器图片输入

沿用现有排版、色彩、按钮与输入框，不重新设计应用。交互参照已确认的ChatGPT附件草稿/发送前预览、Codex输入与执行状态分离、Claude消息附近附件呈现：缩略图紧邻正文，失败保留完整输入，历史点击按需读取，不在列表嵌入像素。

输入来自paste图片item、drop文件和文件选择，含图时拦截同次图片粘贴避免混入截图来源文字。原生纯文字粘贴不拦截。多图按client_id显示、删除、放大；仅图可发；图片存在时斜杠按普通图文发送，避免本地命令吞图。草稿随现有App/会话内存保存，异步读取绑定原会话；页面刷新不保留。服务返回所有额度和模型能力，未知/文字模型保持草稿并阻止发送。

发送逻辑独立模块因useConversation已493行，保留既有并发/会话创建/设置/停止/发送行为。图片附加新协议字段与专用header。服务保留输入元数据列表供用户恢复到输入框，uncertain明确说明可能已进入上下文，显式点击后才处理。仅保存模型实际收到的规范化图，下载和历史预览走认证fetch→Blob→objectURL，切换/卸载释放URL、取消旧请求；不使用URL凭证或持久化草稿。

验证：paste/drop/file、只图/混合、删除、失败保留、模型未知拒绝、会话切换隔离及迟到异步读取；旧文字/指令/停止/会话测试回归；build、桌面/375px与深浅主题在05验证。

实际接线：useConversationDrafts持有单一ComposerDraft{text,images}；字符串/图片ref只是派生读取投影。新建会话移动完整对象，迟到读图/保留恢复绑定原会话，恢复文字与图一次性追加。图片请求在发出前冻结ID/正文；未知结果明确重试原请求，新草稿不覆盖它；明确未接受（含stale_run）解除发送锁并保留输入。冻结对象分别保存实际发送的合并正文text与编辑草稿draftText；成功重试按原draftText清理，避免停止保留文字参与合并后残留已发送的草稿，同时保留后来新编辑的文字。原请求冻结期间，其待发送文字只读，新编辑草稿仍可使用，避免旧回执清理后来改过的保留项。保留正文预览截断时先完整分块读取再恢复，不把预览当正文发送。图片提交/读取期间保留原run停止按钮；普通文字原行为保持。

验证新增红灯：未知图片请求身份丢失、迟到保留恢复文字未落原会话、图片提交时停止按钮缺失；均在原有断言保护下修正。原Composer文字发送模式测试未放宽。提交前复核又复现“停止保留文字＋附图＋未知请求成功重试”后残留原草稿，补齐合并清理及新草稿保护，先红后绿。最新前端68文件546 passed，TypeScript/Vite通过；真实浏览器剪贴板JPEG、原生多PNG文件选择、仅图及图文、文字模型阻止新图、历史图降级继续文字、认证预览/下载、375深浅主题无横向溢出已验证。拖入用DOM行为测试，未声称原生桌面文件拖拽已手工验收。
