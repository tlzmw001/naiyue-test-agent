# 143AU 云端附件统一选择窗口

用户要求一个入口，同时支持文件、文件夹及批量选择。云端任务加号菜单打开同一弹窗。左侧项目位置、常用目录和盘符，右侧普通文件与可进入的目录。支持路径输入、上一级、跨分页保留选中项、一键勾选已加载项。勾选文件夹包含其子项，提交清单移除同一来源内被选中文件夹覆盖的路径。

前端复用 browseDirectories 获取规范路径、目录身份和常用位置，直接打开 cloud-files 文件清单，跳过目录确认。多个来源位置各自保留路径和目录身份，一次点击按来源提交多个已有附件请求。单批仍遵循原上传额度。成功登记的批次立即从待提交清单移除，失败后只从原未确认 ID 继续。服务仍按原身份复核、防链接检查、缓存额度和分段协议工作。

本机多个附件工作协程仅串行准备归档，避免同时抢占输入缓存排他锁。传输仍可并发，等待准备的附件可取消。修改前端附件选择和样式、对应测试、本机附件准备锁及锁文档。Linux Coordinator 与 Runner 协议不变。

本机验证：统一选择入口和并行打包冲突先红后绿。前端覆盖混选、分页、跨盘符批次及部分登记失败后的原 ID 重试；后端覆盖两个附件批次排队并就绪。云端后端与安装烟测1190项、完整前端640项及构建通过。Chromium桌面和375px组件预览通过，见build/spec143au。Windows实机待验证。


提交失败后，保留原批次供直接重试。若需要重新选择，可点击「放弃待确认选择」，清空本次选择并重新读取已登记附件。
