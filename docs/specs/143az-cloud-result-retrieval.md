# Spec 143AZ 云端结果取回窗口

## 范围

沿用云端每轮产物快照、本机材料接收、保存请求预检及执行、浏览器下载、分析草稿和旧任务代码交付。改动限本机前端。结果列表继续使用现有每页 20 条的 API，云端捕获、文件回收和下载协议不变。

## 窗口

- 主视图展示可取回结果及生成、失败、待核对等状态，默认选择最近的可取回结果。最新一页找不到可取回结果时，使用任务已有的留存结果 ID 核对，避免为了找产物遍历历史。空产物、已替代、已放弃及已清理的记录放入历史。旧任务只要还有代码材料仍视为可取回。
- 历史首次打开时读取一页，用户主动翻页，关闭后取消请求。主视图保留对最新一页的刷新。两组以原始结果页为边界，某页没有本组记录时仍可查看更早记录。
- 预览、单文件浏览器下载、勾选和分析保留。分析复用选中材料和来源会话校验，确认发送由主会话完成。窗口关闭、任务切换、轮次切换后，迟到的响应不能修改当前视图或附加分析草稿。

## 保存

- 勾选文件、选择目标目录只更新界面。点击「保存到本地」固定选择，接收材料并登记原保存请求。预检状态可轮询。本次点击发起的请求在预检通过且无冲突时接着执行。目标检查、写前复核、写入日志沿用现有本机接口。
- 只有内容冲突才展示文件清单及独立的「确认覆盖并保存」。换目录、重检或关闭窗口会丢弃未执行的覆盖授权。旧请求、重开窗口或回执不明时先查询原命令，再由用户继续原请求。云端文件已清理时，仍可在历史记录里核对已登记的本机保存。
- 正常路径中，选目录时没有网络写操作，点击保存后依序接收、预检、执行。失败路径中，丢失回执后保留相同命令 ID、材料 ID 和目标身份，重开后只查询状态，避免隐式重放。已持久化的执行可以按原进度继续。

## 验证

前端覆盖目录选择无写入、异步预检后自动保存、同名覆盖、丢失回执和重开恢复、历史分页、切轮晚到响应及既有分析与旧代码路径。运行前端全量测试和生产构建。
