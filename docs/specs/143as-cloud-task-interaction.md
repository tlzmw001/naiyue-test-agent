# 143AS 云端任务首次模型加载、连接与附件交互

用户验收提出三项修复。模型目录随任务 ID、Runner 状态和已登记模型变化重新读取，取消旧请求，保留手动重试。连接默认显示序号，保留内部端口键和自定义名称。操作结果放在对应卡片，关闭置于固定窗口标题栏右侧。

附件沿用主会话加号弹出菜单，复用现有目录浏览器跨盘符选择本机目录，每批在一个选定目录下勾选文件或子目录，跨目录可分批添加。原项目目录仍可直接浏览。现有附件与目录 API 增加可选目录路径和观察身份。服务检查项目授权、目录及祖先安全、目录观察身份，捕获前后复核，复用原文件预算和冻结缓存。路径只保存在本机附件记录。目录变化则停止并报告来源变化。继续通过原任务范围授权发送附件。

传输通过云端分段确认回调写入附件进度，轮询按准备、确认字节百分比、校验和失败显示。缓存命中和断点续传沿用原协议；取消、失败不会伪造成功。新增字段可缺省，兼容旧记录。覆盖首次就绪、外部目录和变更拒绝、确认字节、连接行内反馈。
