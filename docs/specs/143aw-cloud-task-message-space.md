# 143AW 云端任务消息空间与临时气泡

任务详情顶部保留紧凑的一行，包含返回任务列表、状态、折叠箭头。箭头收起或展开完整标题、任务操作、操作记录、过程选择与结果入口。内容区限制高度，消息区使用剩余高度；折叠时保留错误和原命令核对入口。

原临时气泡只在当前分页出现同运行的用户消息时隐藏。现在用已受理命令的 run_id 核对消息或工具活动，同运行已有可见进展，或新鲜任务状态确认同一轮结束时清理临时气泡。切换子线程时不展示主线程临时气泡。旧运行消息不清理新运行的气泡；等待原请求确认时仍保留提交提示。只改前端，不改云端运行或观察协议。

本机验证：折叠与仅有同轮实时进展的气泡先红后绿。覆盖旧运行不能误清理，且气泡清理后不会在分页变化时重现。完整前端643项、TS/Vite构建通过；Chromium桌面展开/折叠及375px折叠截图见build/spec143aw。
