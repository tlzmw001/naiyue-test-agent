## 1. 当前链路及本片修改

原ResearchIndex负责范围/状态/期限/条件/锚点、FTS/RRF候选和权威版本重验；00b select_results负责完整词段优先/覆盖回退。本片不改上述引擎，新增research selector，比较有界候选的主题线索、精确去重与词项多样性排序。

这是第三轮实验，复用并扩展benchmark_tuning的评分/校准/验证/冻结/测试入口，不复制第三套驱动器。增加显式研究selector参数、配置网格和输入路径；实际消费者只有tuning与robustness两个实验，不创建动态插件/注册平台。默认旧调用方式保留，旧冻结重跑使用源码快照；所有新旧行为均由研究测试验证，不改产品API。

文件：新增retrieval_robustness.py、test_robustness.py、robustness-fixtures.json/protocol.json、结果报告；扩展benchmark_tuning.py及必要测试。旧retrieval.py/retrieval_tuning.py及原固定数据不改；当前Spec/交接同步。每文件≤500行。

## 2. 固定样本与标注

36组、144查询，分18组72校准/9组36验证/9组36最终测试。同组改写不跨split；主体8组、多事实8组、重复8组、无答案6组、含混6组，最终测试每类都有样本。包含主题明确、正文后半段才有关键事实、主体与对照提及、一个问题对应多个事实、同事实精确/近重复、相似但条件/值/否定不同的独立规则。

含混问题允许多个合理解释；同组也给出更明确问法，按实际query标注，不用算法看不到的隐含intent判错。样本是手工合成，模板与作者偏差无法由分组消除；不声称真实业务泛化。

fact_groups仅供评分：不同record_id可以指同一已标注事实。算法看不到fact_groups或gold；actual_ids始终保留真实记录ID，evaluation_ids单独用于事实覆盖评分。精确去重误合并独立事实时不能因duplicate_ids得到额外覆盖奖励。

## 3. 对照方法与参数

| 方法 | 行为 |
| --- | --- |
| cascade_base | 00b冻结的1/1/1、完整词段优先、覆盖1/2回退。 |
| coverage_pool | 全候选按覆盖1/2筛选，不因完整表达存在而排除其他事实。 |
| topical_pool | 标题/别名/正文首个分句作主题线索；达到门槛的候选可同时返回。无主题合格项才回退00b。 |
| topical_exact | 同上，仅将同作用域/类型/条件及标题/正文完全一致的记录折成一个展示代表，保留被折叠ID；不删除数据。 |
| topical_diverse | 同精确去重，再用词项Jaccard的MMR降低近重复排名；近似项不硬合并。 |

主题门槛1/3、1/2、2/3；diversity lambda为0.6/0.8/1.0，其他参数固定。共17配置。主题分句仅按标点取得，不宣称识别语义主体；若错误主题压过正文真实事实，必须保留失败。字母/数字/路径锚点在每个query/显式扩展中保持精确，主题片段不能用正文另处的锚点充当自身证明。

MMR=λ×查询词项覆盖比例−(1−λ)×与已选项最大Jaccard相似度；先精确去重，候选至多50、结果至多8。数值、路径、作用域、机器、模块、目标及否定差异的记录不能因近似度而硬合并；仍可能因8条预算排在结果外，按事实召回如实计漏。限定池后处理不解决池外召回。配置质量完全相同时，取更高lambda（更少多样性惩罚），固定在首次评分前，不根据测试改枚举顺序。

## 4. 指标与选型

同时报告记录精确率、不同事实有效返回率（不同相关事实数/返回记录数，重复不重复计收益）、事实召回、macro F1/原F0.5、首条/MRR、冗余条数、各类召回、无答案误返回、禁止项、字节和耗时。按事实的有效率不冒充传统文档precision；同事实副本有用与否的业务权重未来另验。

校准选配置：禁止项/无答案错误更少→正例各类最差召回更高→正例macro F1更高→不同事实有效率更高→首条命中更高→冗余/返回更少→简单配置。验证同序选方法，先保持00的全部必命中/禁止/无答案门禁；00b已观察144条另报回归，不当作新测试。分层不等价于覆盖全体相关事实，因此不强行将旧次相关遗漏当必须保留的行为。

冻结后才运行最终测试，不按测试成绩换方法/改标签。若没有合格方法或新方法更差，允许结论为保留00b或暂不定型。保留每条实际结果、所有失败和原哈希。

## 5. 实现、验证与边界

先做独立失败测试：主体/对照、正文回退、多事实、精确副本与独立近似规则、MMR多样性、显式扩展/技术锚点、fact评分隔离、校准/测试选择不泄漏。研究driver新增参数直接传递，不能依赖隐藏全局替换。原76项全部继续执行；不修改测试基础设施，不为适配新研究删除旧断言。

正常链：固定query→原可信候选→有界主题/去重/多样性→真实record IDs→评分器单独映射fact IDs；失败链：主题启发式漏正文真实事实或候选池被噪声占满→如实空/漏召回；冻结指纹变动/已有输出→非零退出，不伪造成功。所有IO错误保留诊断。

本轮只跑研究测试/compile/标准库/500行/哈希/JSON/链接/diff及旧快照重跑；不把并行Edit修复纳入范围，不以历史产品全量成绩冒充本轮证据。原始证据写build/spec127-00c，结果按split拆分保存，模型调用0。

MMR只借鉴原作者[相关性与新颖性权衡](https://www.cs.cmu.edu/afs/cs/Web/People/jgc/publication/MMR_DiversityBased_Reranking_SIGIR_1998.pdf)，词项相似度与本项目参数是待验证策略，不继承论文效果声明。

## 6. 本片结果

离线实验已执行，[结果报告](../research/memory00/主体多事实与重复噪声实验结果.md)保留全部方法/误召回/遗漏、同参数消融和已观察旧集合回归。验证冻结topical_pool、主题2/3、字段1/1/1；正式测试记录精确率98/102=96.08%、不同事实有效返回率42/102=41.18%、事实召回76.19%、无答案0/8、禁止0。相对00b基线记录精度提高，事实召回未提高；旧24条相关召回92.08%→85.42%，旧00b144条精确率96.00%→93.02%，故不升级为产品默认。

固定1/2门槛验证消融中，精确展示去重将不同事实有效率35.00%→53.72%、事实召回78.13%→94.79%，同时记录精确率75.00%→66.94%；MMR没有再提高事实收益。近重复、池外事实和主体语义仍未解决，不因最终测试低门槛方法召回100%而更换冻结胜者。

研究95项通过，180/180新排名及180/180旧快照排名重跑一致；输出覆盖/链接/指纹拒绝检查通过。原引擎和00b选择器保持哈希不变，研究CLI实际接线，0模型调用。产品01—06仍未实施；下一步先确认相关事实覆盖/重复占位的验收标准，再做单变量精确去重验证，history可以独立安排。
