# Spec143AX 左右侧栏宽度调整

## 现状与边界

`App` 的会话导航默认 260px，辅助侧栏默认 440px。两栏与主会话并排时，主会话在 768px 内容列、原有横向内边距及实际滚动条之外还有空白。用户可以用这部分宽度查看更长的会话标题和云端任务内容。

## 实现

- `Sidebar` 和 `ActivitySidebar` 在靠近主会话的边缘共享拖动把手。拖向主会话加宽，往回拖最窄恢复到现有默认值。支持键盘方向键、Home 和 End。
- `App` 的样式从整体宽度扣除两栏的当前布局基宽和主会话所需宽度，两栏共享余额。拖动一侧只使用剩余余额。窗口缩小时先收回扩出来的宽度，回到默认布局；主会话内容列和工具卡片不改。
- 导航折叠和侧栏浮层时隐藏对应把手。关闭再打开辅助侧栏沿用当前界面的宽度偏好，刷新页面恢复默认。没有 API、配置文件或存储变化。

## 验证

- 前端回归覆盖左右方向、双栏共享余量、恢复默认和折叠。Chromium 核对真实布局中工具卡片和输入框的宽度，以及窗口缩小时的回退。
