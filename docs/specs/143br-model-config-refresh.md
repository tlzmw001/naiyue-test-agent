# Spec143BR 模型配置刷新

模型菜单提供「刷新模型配置」。按钮调用认证的 `POST /api/v1/models/refresh`，按本机服务启动时确定的配置路径重新加载模型。响应沿用现有模型列表的默认模型、可用 ID、推理档位和图片能力。现有模型列表 GET 仍是只读操作。

服务先解析并准备新的目录，再一次性替换项目与会话共用的目录引用。新模型请求按当前目录解析。如果有前台运行或仍占用旧模型的后台记忆任务，返回 409 并提示稍后重试。候选准备前及发布时均核对占用。发布后关闭上一个目录持有的客户端，关闭失败记录诊断。配置无效时保留当前目录，关闭未发布的客户端，返回可读的失败提示。仅启用且注册了记忆工具时，刷新才检查记忆模型配置。

已保存会话保留所选模型 ID、推理档位及历史。网页可以打开检查点有效的就绪会话。若模型或推理档位已不可用，用户可以在模型菜单改选可用配置，改选前禁止运行。仍需恢复的会话继续走原恢复流程。当前草稿不重置。

刷新成功后，当前工作区重新 GET 共用模型目录。切换工作区也会重新读取。刷新 POST 的响应只用于确认操作结果，浏览器按读取顺序处理 GET 响应。

验收使用临时模型目录，覆盖已打开作用域同 ID 配置替换、已保存会话重新选型、无效配置保留上一版本、连续刷新关闭旧客户端、后台占用限制，以及跨项目切换后的列表更新和错误提示。
